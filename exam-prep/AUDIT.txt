СООТВЕТСТВИЕ ЗАДАНИЮ — 28.10.2026
Источник: точный текст задания из Экзамен.docx, сохранён в REQUIREMENTS.txt.

1. API без БД: статические списки в ProductsController и CategoriesController.
2. Две сущности: Models/Product.cs и Models/Category.cs.
3. Два контроллера моделей: GET, POST, PUT, DELETE для обеих сущностей.
4. Health Check: HealthController, GET /api/health, status=Healthy.
5. GitHub: https://github.com/xtwze/examLinux.
6. .NET на VM: SDK 8; версия 6 в задании желательна, не обязательна.
7. Исходники в /home/{пользователь}/app: checkout в $HOME/app/examLinux.
8. Release в /var/www/app (755): каталог создаётся с текущим пользователем
   как владельцем, dotnet publish пишет прямо в него без sudo.
   В задании не требуется владелец root:root или пользователь www-data.
9. systemd: examapi.service запускает /usr/bin/dotnet /var/www/app/ExamApi.dll;
   при установке User=YOUR_USER заменяется текущим обычным пользователем.
10. HTTP 5000: appsettings.json задаёт http://127.0.0.1:5000.
11. Nginx: HTTP 80 проксируется на 127.0.0.1:5000; Host сохраняется для
    корректного Location после POST из Windows через NAT :8080.
12. Запросы из Windows: START §6 и WINDOWS.ps1 для демонстрации CRUD.
13. История команд: START §7, history в интерактивном Bash.

Проверки этого пакета и их ограничения: VERIFICATION.txt.
Реальная VirtualBox VM, Windows и автозагрузка после reboot требуют
демонстрации на экзамене; контейнерная проверка их не подтверждает.
Docker, БД, HTTPS и CI/CD заданием не требуются.
