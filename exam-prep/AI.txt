ИИ для подсказок по учебному Linux

Основной вариант при интернете — открыть знакомый чат в браузере Windows,
вставить AI-CONTEXT.txt, затем текст ошибки и вывод команды. Установка
агента, Node.js, Python, Docker или API-ключа для этого не нужна.
Обычный чат не видит VM автоматически: данные нужно передать самому.

Вариант без интернета — Ollama НА WINDOWS, вне Linux VM.
Подготовь заранее на том компьютере, где будешь работать:
1. Установи Ollama для Windows с https://ollama.com/download/windows.
2. Открой Ollama, затем PowerShell:
     ollama pull qwen2.5:3b
     ollama run qwen2.5:3b
3. Вставь контекст из AI-CONTEXT.txt и свой вопрос.
   /bye завершает разговор.
4. Проверь работу заранее с отключённым интернетом.

Эта модель есть в каталоге Ollama; загрузка около 1.9 GB.
Это размер файла, а не требование к RAM. Скорость и память зависят от ПК,
длины контекста и параллельно работающей VM. Небольшая модель ошибается;
не рассчитывай на неё без пробного вопроса и проверки команд.
Не ставь модель в слабую экзаменационную VM: она отнимет ресурсы у задания.

Опционально готов ASK-LOCAL.ps1 — одна подсказка с контекстом проекта:
     .\ASK-LOCAL.ps1 -Question 'Nginx returns 502. What should I check?'
Скрипт обращается только к локальной Ollama на Windows, порт 11434;
читает AI-CONTEXT.txt рядом с собой и отправляет вопрос. Он не читает VM,
не собирает логи, не исполняет предложенные моделью команды и не хранит
переписку между запусками. Ошибку вставляй в вопрос сам.
Если Windows блокирует .ps1, проще использовать ollama run и вставить
контекст вручную; не требуется менять глобальную политику PowerShell.

Полноценный агент с доступом к shell практически возможен, но здесь
добавит установку, вход в аккаунт/модель и контроль команд. Для задания
короткая шпаргалка плюс чат-помощник быстрее и предсказуемее.
ИИ не требуется ни одним пунктом «Экзамен.docx». В документе также нет
разрешения на ИИ во время зачёта: используй его при подготовке, а на
самом зачёте — если такой формат помощи разрешён преподавателем.

Статус: инструкции и клиент подготовлены; реальный запуск Ollama,
качество ответов и доступность сетевого чата на экзаменационном ПК
не проверялись. Модель в этом сеансе не скачивалась.
